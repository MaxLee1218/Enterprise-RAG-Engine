# Changelog

All notable changes to this project are documented here. The project has not
yet published a stable compatibility guarantee.

## Unreleased

### Added

- Read-only browser demo for the existing `/ask` API contract.
- Full Docker Compose topology for the API, Redis, persistent data, and
  explicit one-shot ingestion.
- GitHub Actions validation for the offline test suite and synthetic corpus.
- Portfolio-oriented README visuals, evidence links, architecture decisions,
  contribution guidance, and security scope.

### Changed

- Repository presentation now separates reproducible verification from dated,
  provider-dependent evaluation snapshots.
- Detailed setup and evaluation instructions are linked from the concise
  project overview.

## 0.1.0 — 2026-10-05

- Modular ingestion, retrieval, reranking, grounded generation, API, CLI,
  evaluation, FAQ routing, conversation-aware rewriting, and non-root Docker
  runtime.
